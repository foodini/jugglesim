# --- 2 jugglers (passing) ---
# Juggling Lab's passing notation: <juggler 1's throws|juggler 2's throws>; "p" is a pass.
<3p|3p>                                 ; Ultimates             ; props=clubs
<3p 3|3p 3>                             ; 2-count               ; props=clubs
<3p 3 3|3p 3 3>                         ; 3-count               ; props=clubs
<3p 3 3 3|3p 3 3 3>                     ; 4-count               ; props=clubs
<3p 3 3 3 3 3|3p 3 3 3 3 3>             ; 6-count               ; props=clubs
<4p 3|3 4p>                             ;                       ; props=clubs
<4p 3|@1[1],LRswap>                     ; 7-Club 2-Count     ; props=clubs
<4p 3 3 3|3p 2 3 3>                     ; R2R Double in 4-count ; props=clubs

<3p 3p 3p 6 6 6 | 6 6 6 3p 3p 3p>       ; 9-club W

# --- 3 to 6 jugglers ---
# With three or more jugglers, the target follows the "p": 3p2 is a pass to juggler 2.
# (JuggleSim also reads relative targets, 3p+1 for the next juggler, but these are written as
# Juggling Lab writes them.) Jugglers stand around a ring, J1 nearest the camera and the
# numbers going clockwise (J2 on J1's left).
# A part can be a link: "@1[3]" does what J1 does, starting from J1's throws[3] (the throw
# 3 beats after J1's first, counting from 0 like an array index; "@1" is "@1[0]"). ",LRswap"
# after a part swaps that juggler's hands.
<3p2 3|3p3 3|3p1 3>                                             ;          ; props=clubs
<3p2 3p3|3p3 3p1|3p1 3p2>                                       ;          ; props=clubs
<3p2 3 3p3 3|3p1 3 3 3|3 3 3p1 3>                               ; Feed     ; props=clubs
<3p2 3 3 3|3p3 3 3 3|3p4 3 3 3|3p1 3 3 3>                       ;          ; props=clubs
<3p2 3 3p3 3 3p4 3|3p1 3 3 3 3 3|3 3 3p1 3 3 3|3 3 3 3 3p1 3>   ; Feed     ; props=clubs
<3p+3 3 3 3|3p+3 3 3 3|3p+3 3 3 3|3p+3 3 3 3|3p+3 3 3 3>         ; Star     ; props=clubs
<3p+1 3p+2 3p+3 3p+4 3|@1[3]|@2[3]|@3[3]|@4[3]>                 ; One-Count Feast           ; props=clubs
<3p-1 3p-2 3p-3 3p-4 3|@1[2]|@2[2]|@3[2]|@4[2]>                 ; One-Count Feast, Reversed ; props=clubs
